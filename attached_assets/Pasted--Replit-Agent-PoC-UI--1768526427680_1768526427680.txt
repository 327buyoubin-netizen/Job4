너는 Replit Agent야. 아래 PoC를 “작동하는 데모” 수준으로 빠르게 구현해줘. 절차는 단순해야 하고, 입력/출력이 UI에서 한눈에 보이게 만들고, 시각화로 결과를 분명히 확인할 수 있어야 해.

[프로젝트 개요]
- 취준 일정 + 문서(경험/자소서) 통합 관리 PoC
- 목표 1: 관심 기업 채용 사이트 URL만 입력하면 채용 일정이 자동으로 캘린더에 등록되는 흐름을 PoC로 구현
- 목표 2: 한 번 입력한 경험 데이터를 자소서 문항에 맞게 자동 매칭해주는 PoC 구현

[중요 UI 요구사항]
1) “메타데이터 생성” 버튼이 반드시 있어야 함
   - (채용 URL → 공고 메타데이터 생성)
   - (경험 데이터 → 경험 메타데이터 생성)
2) 입력(Input)과 출력(Output)이 화면에서 명확히 분리되어 보여야 함
   - 좌측: Input 영역 / 우측: Output 영역 같은 구조 권장
3) 시각화(Visual)로 결과를 분명히 확인 가능해야 함 (UI/UX 중심)
   - 채용 일정: 캘린더 뷰 + 테이블 뷰
   - 문항-경험 매칭: 매칭 스코어(%) 막대그래프/리스트 + 하이라이트
4) 너무 복잡한 절차 금지
   - 회원가입/로그인 없음
   - 설정 최소화
   - “URL 입력 → 버튼 클릭 → 결과 확인” / “문항 입력 → 버튼 클릭 → 매칭 확인” 정도로 끝

[기능 범위(반드시 포함)]
A. 채용 일정 수집/표시(데모)
- Input: 채용 공고 페이지 URL 1~3개 입력(멀티 입력 가능)
- 버튼: “메타데이터 생성(채용)”
- Output:
  1) 추출된 공고 메타데이터를 테이블로 표시
     - 회사명(가능하면), 공고명, 시작일(없으면 null), 마감일, 링크
  2) 캘린더 시각화(월간 캘린더)로 마감일 이벤트 표시
  3) “ICS 다운로드” 버튼(캘린더 파일 다운로드) 제공 (실제 Google 연동은 PoC에서는 생략 가능)

※ 크롤링이 사이트별로 어려울 수 있으니 “2단계 방식”으로 구현해라:
- 1순위: 서버에서 URL fetch + 파싱(가능한 경우)
- 2순위(실패 시): 사용자가 공고 내용을 붙여넣는 “HTML/텍스트 붙여넣기” 입력창 제공 → 동일한 파서로 메타데이터 생성
  (즉, PoC는 ‘자동화 흐름’이 보이면 되고, 크롤링 100% 성공이 목표가 아님)

B. 경험 DB + 문항 자동 매칭(데모)
- Input(경험 데이터 입력 폼):
  - 경험 제목, 역할, 기간, 핵심 행동(3줄), 성과(수치 포함 권장), 키워드(태그)
- 버튼: “메타데이터 생성(경험)” → 경험을 구조화(키워드/역량 태그 추출)하여 저장
- Input(자소서 문항 입력):
  - 문항 텍스트 1개
- 버튼: “자동 매칭”
- Output:
  - 문항과 가장 적합한 Top 3 경험을 카드로 표시
  - 각 카드에 매칭 점수(0~100)와 “매칭 근거 키워드”를 표시
  - 가장 높은 경험 1개에 대해 자소서 초안(5~8문장) 자동 생성(간단 규칙 기반 or LLM 사용 가능)
  - 시각화: Top3 점수 막대그래프 or 프로그레스 바

[기술 스택(권장, 단순하게)]
- 한 개의 Replit 프로젝트에서 실행되는 풀스택
- Next.js(React) + API Routes 또는 Express
- 저장: SQLite 또는 파일 기반(JSON) (PoC니까 간단히)
- UI: Tailwind 사용 가능
- 시각화: 가벼운 라이브러리(예: Chart.js) 또는 간단한 progress bar

[화면 구성(필수)]
- 상단 탭 2개:
  1) “채용 일정”
  2) “자소서 매칭”
- 각 탭 내부는 “Input 패널 / Output 패널” 2열 레이아웃
- 각 탭에 반드시 “메타데이터 생성” 버튼이 보이게 배치

[데이터 모델(최소)]
- JobPosting:
  - id, company, title, startDate, endDate, url, createdAt
- Experience:
  - id, title, role, period, actions[], results, tags[], extractedSkills[], createdAt

[파서/매칭 로직(간단 규칙으로 시작)]
- 채용 파서:
  - 날짜 패턴(YYYY.MM.DD, YYYY-MM-DD 등) 정규식으로 마감일 탐지
  - title/company는 meta 태그/헤더에서 추출 시도, 실패 시 placeholder
- 문항-경험 매칭:
  - 문항에서 키워드 추출(명사 중심 단순 토큰화)
  - 경험 tags/extractedSkills와 겹치는 개수 기반 점수화
  - 점수 = 100 * (겹침키워드수 / (문항키워드수 + 1)) 같은 단순식으로 구현

[완성 기준]
- 로컬 실행 버튼 누르면 즉시 동작
- 샘플 데이터(예시 URL 1개 + 경험 2~3개) “Load Sample” 버튼으로 자동 입력 가능
- 각 버튼 클릭 시 로딩 상태/성공/실패 메시지가 명확히 표시
- 사용자가 “입력 → 버튼 클릭 → 시각화된 결과 확인”을 1분 안에 할 수 있어야 함

이 요구사항을 충족하는 코드와 파일 구조를 생성하고, 실행 방법까지 함께 제공해줘.
